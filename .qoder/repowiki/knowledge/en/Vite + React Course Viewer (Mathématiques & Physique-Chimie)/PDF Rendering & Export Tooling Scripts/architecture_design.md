Flat collection of independent CLI/utility scripts with no shared library — each file is self-contained and invoked directly from the repo root.
- Python side (`*.py`): uses PyMuPDF (`fitz`) to open PDFs in-process; `analyze-pdf-pages.py` inspects embedded image bboxes per page, `render-pdf-region.py` renders a fractional vertical band at a given zoom into PNG, `extract-pdf-text.py` / `search-pdf-ions.py` extract or search text content.
- JavaScript side (`*.mjs`): uses Puppeteer with a headless Chromium instance (hardcoded `executablePath` to Chrome on Windows) to drive the live app at `http://localhost:4173/`. `export-pdf-test.mjs` navigates the UI, clicks the physics course export button, and waits via CDP `Browser.downloadProgress` for the generated PDF download; `pdf-pages-to-png.mjs` opens a local PDF via `file://` URL with `#page=N&zoom=100` hash fragments and screenshots each page; `inspect-correction.mjs`, `export-pdf-test2.mjs`, `export-pdf-test3.mjs` are variant iterations of the same Puppeteer-driven export workflow.
- Dependency direction is one-way: scripts depend on the running dev server and on external binaries (Chrome, PyMuPDF); nothing inside this module is imported by the app.
