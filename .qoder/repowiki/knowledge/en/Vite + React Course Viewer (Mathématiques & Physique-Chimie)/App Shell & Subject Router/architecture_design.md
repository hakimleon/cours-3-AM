- `src/main.tsx` is the single DOM bootstrap: imports KaTeX CSS, then renders `<App />` inside React StrictMode via `react-dom/client`'s `createRoot`.
- `src/App.tsx` is the top-level orchestrator. It owns two independent state trees — one for Math (selected course, active section, curriculum/treatise view mode) and one for Physics-Chemistry (home/course view mode, completed/favorite lists persisted to `localStorage` under keys `pc_3am_completed_courses` / `pc_3am_favorites`). A single `activeSubject: 'math' | 'physics'` switch decides which branch (`PhysicsModuleHomePage`/`PhysicsCourseView` vs. `CurriculumProgressPage`/`GeometryTreatisePage`/`CourseSectionsRenderer`) is rendered.
- Global providers are layered at the root: `ImageLightboxProvider` wraps everything, and `ConceptModalProvider` is nested inside to let child components open the geometry treatise by property id.
- PDF export is coordinated centrally through `handleExportCoursePdf` / `handleExportPhysicsCoursePdf`, which call `utils/exportCoursePdf` helpers and surface progress via a floating toast; both branches share an `isExportingPdf` + `pdfExportStatus` pair so only one export runs at a time.
- `src/types.ts` defines the Math data model (`Course`, `CourseSection`, `DiscoveryActivity`, `ExerciseItem`, `VocabularyItem`, visual-model discriminants).
- `src/typesPhysicsChemistry.ts` defines the parallel Physique-Chimie model (`PhysicsChemistryCourse`, discriminated `PhysicsContentBlock` union of paragraph/bullets/quote/discovery/experience/schema/table/formula/activity/callout/simulation blocks, plus domain-scoped schema types). It re-exports `PhysicsSimulationBlockData` from the physics component subtree, establishing a one-way dependency from this shell into the physics UI layer.
- `src/index.css` sets up Tailwind v4 (`@import "tailwindcss"`), KaTeX overrides forcing LTR math rendering on an RTL page, CSS custom properties for the cream/magenta palette, and print/PDF-export media rules that hide chrome and force RTL layout for captured content.
