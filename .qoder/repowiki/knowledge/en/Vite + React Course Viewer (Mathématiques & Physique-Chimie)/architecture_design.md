The root is a Vite application whose entry point (app_shell) mounts sibling subject modules — Mathématiques and Physique-Chimie — and wires routing between them. Shared data contracts live at the root so both subjects consume the same types. The pdf_tooling_scripts child uses Puppeteer (bundled as a devDependency) to render pages of the built app into PDFs, while pdf_artifacts_and_references holds the resulting page screenshots and diffs used to validate print layout. metadata.json declares platform capabilities (e.g., server-side Gemini API) consumed by the shell. Build/dev tooling is centralized in vite.config.ts (Tailwind v4 plugin, React plugin, `@` alias resolving to the repo root).
